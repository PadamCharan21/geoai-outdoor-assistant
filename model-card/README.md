# Fieldnote GeoAI SLM

This public repository is intended to contain the unmodified weights and tokenizer for [Qwen/Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct), together with a project configuration. The model has 0.5 billion parameters and is licensed under Apache-2.0 by its upstream authors.

## Intended use

The GeoAI Outdoor Assistant provides live weather, air-quality, and OpenStreetMap evidence to this model to produce a short user-facing summary. The model does not fetch data or decide the venue ranking. Deterministic Python logic computes recommendation scores, and the API returns its supporting measurements and source list.

## Loading

After running `python scripts/publish_model.py YOUR-HF-USERNAME/fieldnote-geoai-slm`, load the public repository with:

```python
from transformers import AutoTokenizer, AutoModelForCausalLM
repo = "YOUR-HF-USERNAME/fieldnote-geoai-slm"
tokenizer = AutoTokenizer.from_pretrained(repo)
model = AutoModelForCausalLM.from_pretrained(repo)
```

## Limitations

This is not a fine-tune and makes no new model capability claim. Outputs can still omit or misstate prompt details; the app provides its independently computed evidence and practical cautions alongside the generated summary. Do not use it for medical diagnosis or as a substitute for official safety advisories.

## Data sources used by the application

Open-Meteo Weather Forecast API, Open-Meteo Air Quality API, Open-Meteo Geocoding API, and OpenStreetMap via Overpass API. See the source code README for request and attribution details.
